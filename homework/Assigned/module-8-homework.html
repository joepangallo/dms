Assignment

Write ten scripts — run seven, hand-write three

  1. Use the exact table and column names shown above.
  2. Complete each task in its own box. Every Run starts from the original data, so begin each script with the DROP ... IF EXISTS housekeeping it asks for.
  3. Tasks 5, 7, and 9 are MySQL stored-program code. The in-page runner is SQLite and cannot execute CREATE PROCEDURE, so those boxes have a Check structure button instead of Run — it confirms the required pieces are present but does not run or judge the code. Write it exactly as you would for MySQL, and it is graded from what you print.
  4. Include every requested SELECT so the result can be graded.
  5. Task 10 is supposed to end with an error. The trigger's error message printed under your results is part of your evidence — do not remove the failing statement.

Audit changes with a trigger

A delivery just arrived, and the owner wants every stock movement on record. Start with DROP TRIGGER IF EXISTS LOG_STOCK_CHANGE and DROP TABLE IF EXISTS STOCK_LOG. Create a table STOCK_LOG with LOG_ID INTEGER PRIMARY KEY, ITEM_ID CHAR(4), OLD_ON_HAND INTEGER, and NEW_ON_HAND INTEGER. Create a trigger LOG_STOCK_CHANGE that fires AFTER UPDATE OF ON_HAND ON ITEM, FOR EACH ROW, with a WHEN OLD.ON_HAND <> NEW.ON_HAND clause, inserting the item ID with its old and new counts into the log. Then run two updates: set SB40 to 21 on hand (the delivery), and "set" BP10 to 14 — the count it already has. End by selecting the log: exactly one row, because the trigger's WHEN clause ignored the update that changed nothing.
